Installation / start here

Install Coffee Client

Pick the download for your computer. You do not need Node.js, npm, or the source code to use the launcher.

Open the official downloads, then expand Assets on the release page. Version numbers in filenames change with each release.

WINDOWSWindows 10 & 1164-bit Intel / AMD PC. Choose Coffee-Client-Setup.exe. MACIntel & Apple SiliconmacOS 12 Monterey or newer. Choose the mac-universal.dmg preview. LINUXLinux x6464-bit Intel / AMD desktop. Choose the .AppImage download.

Which files do I need?

Download just the installer, disk image, or AppImage for your system. The Mac .zip is an alternative to the disk image, not an extra requirement. Files ending in .yml or .blockmap support automatic updates; you do not open them. The coffee-build-*.json files are release verification records, not installers. Source code archives are for developers, not installation.

Use the official release page. Coffee Client's current Windows installer is not publisher-signed, and its Mac preview is unsigned and not notarized by Apple. Security warnings can appear because the operating system cannot verify the publisher. That is not proof that a file is safe. Verify the download's source before deciding to open it.

After installation

  1. Open Coffee Client and choose Sign in with Microsoft. Sign in only on Microsoft's website in your browser, then return to the launcher. Microsoft may ask for account consent or two-step verification.
  2. Make a profile, choose a Minecraft version and loader, and launch. Java Edition online play requires an account that owns Minecraft.
  3. Allow time for the first launch to download Minecraft, the required Java runtime, and loader files. You do not normally need to install Java yourself.

The requirements above describe the current Electron 41-based launcher, not every Minecraft version or modpack. Individual games can need newer graphics drivers, more memory, or a newer operating system. Electron platform support.

Installation / Windows

Windows 10 & 11

Use a 64-bit Intel or AMD Windows PC. The standard download is the installer, not the source archive.

  1. Open the official release and download Coffee-Client-Setup.exe from Assets.
  2. Open the completed download. Review any Windows security prompt using the explanations below.
  3. Follow the setup window, review the license, and choose an installation folder you can write to. Finish setup and open Coffee Client from its shortcut or the Start menu.
  4. Connect your Microsoft account, then create a profile. You do not need the Dev Mode batch file.

Pop-ups you might see

Download is uncommon or cannot be verified

Some browsers warn about downloads that are new, unsigned, or not widely downloaded. Check that you came from the official GitHub release and that the filename matches. A browser warning is not a malware scan result or a guarantee of safety. Do not disable browser protection to download it.

Windows protected your PC

Microsoft Defender SmartScreen may not recognize the unsigned installer. If you have verified its origin and choose to trust it, More info may offer Run anyway. Read the file and publisher details first. If your PC does not offer this option, a security policy may block it; do not turn off SmartScreen or work around a school or work policy.

Do you want to allow this app to make changes?

This is User Account Control. It may appear if setup needs administrator permission, such as installing into a protected folder. Unknown publisher means Windows cannot verify a publisher signature. Check the app and its source before approving. Routine launcher use should not require running as administrator.

Windows Security or firewall access

Java or a locally hosted Minecraft server may ask to receive network connections. This is separate from installing Coffee Client. For local play with friends, allow only the network types you actually need; do not automatically select public networks. Ordinary downloads and Microsoft sign-in do not require opening an inbound firewall port.

A threat detection is different. If antivirus reports malware or a specific threat, stop and report the exact message. Do not disable antivirus or add a blanket exclusion for Coffee Client.

Updates & common problems

The installed Windows version supports launcher updates. Keep its installation folder writable. A portable build, if offered, does not use the same automatic update path. On Windows in S mode or a managed PC, installation outside the Microsoft Store may be blocked; ask the device owner or administrator.

Windows 7, Windows 8, and 32-bit Windows are not supported by the current launcher. Windows on ARM is not a separately tested native build. Windows 10 compatibility does not extend Microsoft's operating-system security support.

Installation / macOS

macOS

One universal download for Intel and Apple Silicon Macs. The current launcher requires macOS 12 Monterey or newer.

Mac preview: this build is unsigned and not notarized by Apple. Automatic launcher updates and public friend-sharing are not supported in this preview. Local server hosting is available. Download future Mac versions from the official release page.

  1. Choose About This Mac from the Apple menu to check your macOS version. An Intel processor and an Apple M-series chip both use the mac-universal download.
  2. Open the official release and download Coffee-Client-<version>-mac-universal.dmg.
  3. Open the disk image and drag Coffee Client into Applications. If you chose the .zip instead, extract it and move the app into Applications. Do not launch from inside the archive or mounted disk image.
  4. Eject the disk image, then open Coffee Client from Applications. If macOS blocks it, read the matching section below before deciding whether to allow it.

Newer macOS: Ventura 13 and later

Try opening the app once, then open Apple menu / System Settings / Privacy & Security. Under Security, macOS may show that Coffee Client was blocked. If you trust the official download, choose Open Anyway, review the confirmation, and authenticate if asked. Wording and button locations vary by release.

On Sequoia 15 and newer, Control-click / Open is not a reliable way to approve an unverified app. Use Privacy & Security. If there is no Open Anyway option, check the warning itself and any device-management restrictions rather than disabling Gatekeeper.

Older supported macOS: Monterey 12

After trying to open the app, go to Apple menu / System Preferences / Security & Privacy / General. If offered, Open Anyway approves just this app after you review the warning. Unlock the pane if macOS asks. Monterey may also offer Control-click the app / Open, followed by an Open confirmation, for an unidentified-developer warning.

Big Sur 11, Catalina, and earlier

The current launcher cannot run on these macOS versions. An older Intel Mac is not automatically incompatible, but its installed macOS must meet the requirement. Upgrade macOS only if Apple supports that upgrade on your Mac. There is no verified legacy Coffee Client build to recommend here; do not download unofficial repacks or disable security features to force the current app to start.

What the warnings mean

Downloaded from the internet / are you sure you want to open it?

This is macOS's first-open check for a downloaded app. Verify the source and app name before choosing Open. The prompt is not asking for your Microsoft password.

Unidentified developer / Apple could not verify this app

The preview has not completed Apple's publisher-signing and notarization process, so Apple cannot verify it in the usual way. The per-app approval steps above are an explicit trust decision, not proof that a download is safe. Read Apple's explanation.

App is damaged / will damage your computer / malware detected

Stop. These are not interchangeable with a routine unidentified-developer warning. Remove the suspect download, get a fresh copy from the official release, and report the exact message if it persists. Do not use terminal commands to strip quarantine, disable Gatekeeper, or bypass malware protection.

Password, Touch ID, folder access, or incoming connections

macOS may request your Mac login to approve an app or copy it into Applications. That is not your Microsoft login. Folder access can appear if you choose a protected location; grant only the access you intended. An incoming-network prompt usually relates to Minecraft Java or local server hosting, not normal sign-in. A universal build should not normally require Rosetta; if prompted, check that you downloaded the universal app.

Bedrock / Minecraft for Windows is not available through the Mac launcher. Minecraft versions, graphics requirements, and mods have their own compatibility limits. Get help.

Installation / Linux

Linux

Coffee Client is available as an x64 AppImage for Intel and AMD desktop computers. No package installer or source build is normally needed.

  1. Use a current desktop distribution with x64 support. The published AppImage targets x86_64 / amd64, not ARM devices such as Raspberry Pi. Distribution libraries and security policies can affect compatibility.
  2. Open the official release and download Coffee-Client-<version>.AppImage.
  3. Move it to a permanent folder you own, such as Applications in your home directory. Keep the AppImage writable if you want automatic updates.
  4. Right-click the file and open Properties / Permissions. Enable Allow executing file as program or Is executable; the exact label depends on your file manager.
  5. Double-click the AppImage. If asked whether to execute or open it as a file, choose the run option only after checking it is your official download.

Prefer the terminal?

Open a terminal in the folder containing your download. Substitute its exact filename for Coffee-Client-VERSION.AppImage: 

chmod +x "Coffee-Client-VERSION.AppImage"
./"Coffee-Client-VERSION.AppImage"

chmod +x grants execution permission to that file; it does not install system packages or require administrator access. Do not run the launcher with sudo.

Messages you might see

Permission denied / file is not executable

Check execution permission and move the file off a read-only or noexec drive. The AppImage must be on a filesystem that permits execution. Changing permissions alone cannot override a no-execution mount policy.

AppImages require FUSE / libfuse.so.2 is missing

Some AppImages use the FUSE 2 compatibility library to mount their contents. Your distribution may only include FUSE 3. On Ubuntu 24.04, the compatibility package is libfuse2t64; on Ubuntu 22.04 it is libfuse2. Package names differ elsewhere, so follow the AppImage FUSE guide for your distribution. Do not remove FUSE 3 or install random replacement libraries.

Authentication required

Your software manager may ask for your Linux account password when installing a missing system library. Normal AppImage launch does not need that password. Microsoft sign-in belongs in your browser, not in an administrator prompt.

No usable sandbox / user namespace or AppArmor error

Some distributions restrict the browser sandbox used by Electron apps. Save the exact terminal output and check the distribution's supported policy for AppImages. Do not use --no-sandbox, run as root, or disable AppArmor system-wide as a routine fix.

Nothing opens / missing library / GLIBC error

Run the AppImage from a terminal to see the actual error. Older distributions may lack required system libraries; an AppImage does not bundle every component of the operating system. Update through your distribution's supported tools, or send the error with your distro version and architecture when asking for help.

Updates & first launch

Automatic updates are supported for the writable Linux x64 AppImage, not arbitrary extracted or unpacked builds. Desktop-menu integration depends on your system; the file itself remains the launcher. On first game launch, Coffee Client downloads the required Minecraft and Java files. Bedrock / Minecraft for Windows is not supported on Linux.

Linux does not have one universal set of pop-ups: wording varies by distribution and desktop. If a security tool reports a threat, stop and report it rather than adding an exclusion. Get help.

Launcher / profiles

Make a profile

A profile keeps a Minecraft version, loader, and its game content together.

  1. Open the Launcher view and click New profile / Import pack.
  2. Stay on the New profile tab. Enter a Profile name.
  3. Choose a Mod loader. Pick Vanilla if you do not need mods.
  4. Choose a Minecraft version from the versions available for that loader.
  5. Click Create profile. Select your new profile in the list, then use the launch button to play.

Which loader? Use the one your mods or modpack require. Fabric, Quilt, Forge, and NeoForge mods are not interchangeable. When in doubt, start with Vanilla.

After you create it

The selected profile shows its name, version, loader, and player name on the Launcher screen. You can open Mods, Shaders, or Texture Packs for that profile. These are separate from another profile's content.

For an existing Modrinth or CurseForge pack, use Import a modpack instead of recreating it by hand. To copy a profile, see Duplicate a profile.

Launcher / play

Launch your game

The first launch prepares Minecraft, its loader, and any files your profile needs. Later launches can reuse them.

  1. Select a profile in the Library. Check its Minecraft version and mod loader in the main panel.
  2. Check the active account under Settings → Account. Without a connected Microsoft account, the Player name field is used for offline play.
  3. Click Launch Minecraft and watch the status and download progress. Keep Coffee Client open while it prepares.
  4. Wait for the game window. If the launcher reports an error, open Console and check the newest messages.

First-launch checks

If a loader or Minecraft version is unavailable, refresh versions and confirm the profile still matches its mods. A modpack's version and loader are fixed in its profile to protect compatibility. To try another version, duplicate the profile and review any mod warnings.

Before changing Java or memory: let the normal launch attempt finish and read its error. Those controls are under Advanced features, but changing them blindly can hide the real problem.

Launcher / Windows edition

Play Bedrock Edition

Coffee Client opens Minecraft for Windows when it is already installed on this PC.

  1. On Windows, click New profile / Import pack and stay on New profile.
  2. Choose Bedrock Edition as the mod loader, name the profile, and click Create profile.
  3. Select that profile and click Launch Minecraft. If Minecraft for Windows is missing, install it first and try again.

Bedrock is separate from Java Edition. Coffee Client's Java mod, shader, Java account, and Java runtime controls do not manage the Windows game. Sign in and manage Bedrock content inside Minecraft for Windows.

Launcher / library

Manage profiles

Each Library entry is a separate game setup. Select one before changing its mods or launch settings.

Find or rename one

Use Search profiles above the Library list to narrow it down. Select a profile to see its name, player name, version, and loader. Edit the visible profile name; Coffee Client saves that with the profile when you switch profiles or launch.

Copy or remove one

Duplicate makes a new profile and can target another Minecraft version; review the compatibility warning before confirming. The trash button removes the selected profile from the Library after confirmation. It does not delete the profile folder from disk, and the last remaining profile cannot be removed.

Removing a profile from the list is not a disk-cleanup tool. Open its game folder first if you need to keep worlds, screenshots, configs, or saves, and see Find your files.

Launcher / profiles

Import a modpack

Coffee Client can make a new profile from a Modrinth .mrpack or CurseForge export .zip.

  1. Get a Modrinth .mrpack or CurseForge modpack export .zip from a source you trust.
  2. In Launcher, click New profile / Import pack, then open Import modpack.
  3. Click Choose file, or drop the file onto the import area.
  4. Review the pack preview. Set its Profile name; choose Include optional mods only if you want them.
  5. Click Import modpack and wait for it to finish. Then choose the new profile in the Launcher list.

Important: A CurseForge pack needs manifest.json inside the ZIP; an arbitrary ZIP of mods is not a modpack export. Most CurseForge packs also need authorized CurseForge API access to fetch their listed files. Coffee Client shows an error if that access is missing or a file cannot be downloaded automatically. Import never copies account credentials, and the pack's Minecraft version and loader stay fixed in the normal profile form.

Before you launch

Make sure your account is selected if you need online play. Let the first launch finish downloading the game and loader files. If a pack asks for optional files that were not included, you can manage content from the profile's Mods, Shaders, and Texture Packs views.

Settings / account

Add an account

Connect your Microsoft account to use your owned Java account for online play.

  1. Open Settings and select Account.
  2. Click Sign in with Microsoft. Complete sign-in in the Sign in to Coffee Client window.
  3. Return to Coffee Client and select the account you want to play with. Use Use on its row if it is not active.
  4. To connect another account, choose Add another Microsoft account. To disconnect one, use Remove account on its row.

Offline play: When no Microsoft account is connected, the Launcher uses the Player name you enter for offline launches. Sign in for authenticated multiplayer and for applying a skin to a Java account.

Bedrock Edition handles Microsoft sign-in inside Minecraft for Windows; the Java account list here is separate.

Switch or sign out

Click Use on another account row to make that Java account active for the next authenticated launch and account cosmetics. Use Remove account for one connection, or Sign out all accounts when you want to disconnect every saved Java account.

Launcher / content

Mods, shaders & packs

Choose a profile first, then add content that matches its Minecraft version and loader.

  1. In Launcher, select the profile you want to change.
  2. Click Mods, Shaders, or Texture Packs above the launch form.
  3. Browse available projects or use the import controls for files you already have. Check the Minecraft version and loader before installing.
  4. Open your installed content in the same view to manage it. Changes to one profile do not automatically change another.

Compatibility matters. A mod built for one loader or Minecraft version may prevent the game from opening on another. For a broken launch, disable your most recently added mod and try again.

Imported modpack profiles keep their own content and are not automatically given Coffee Client's usual added mods. The pack's setup stays separate from your other profiles.

Launcher / content

Browse content

Find a version that fits the profile you have selected, then install it only there.

  1. Select a Java profile and open Mods, Shaders, or Texture Packs.
  2. Choose Browse, then pick Modrinth or CurseForge. Search for the project you want.
  3. Use Previous and Next above or below results to move between pages. Open a result to review its description and available versions.
  4. Choose a compatible version and click Install. Required dependencies are included when the provider makes them available.

CurseForge access: direct browsing and downloads need authorized CurseForge access configured for this launcher. If it is unavailable, use the publisher page or import a local file you already have. Do not treat a failed download as an installed mod.

Shaders still need a compatible shader engine in Minecraft. A texture pack can be installed into the profile but must also be selected in Minecraft's resource-pack menu.

Launcher / content

Import local files

Already have a mod, shader, or texture pack on disk? Add it to the selected profile instead of downloading it again.

  1. Select the profile and open its Mods, Shaders, or Texture Packs window.
  2. Click Import and select the file, or drop it into the content window.
  3. Switch to Installed to see it. Select a file for Show file, Remove, or the Enabled switch on mods.
  4. Click Find artwork if imported files only show filenames. This checks for exact matches on Modrinth and can add titles, artwork, and descriptions.

Manual imports are not a compatibility check. Use a mod file made for the profile's Minecraft version and loader. Find artwork sends file fingerprints, not the files themselves, to Modrinth; unmatched files stay as they are.

For a complete exported pack, use Import a modpack. Importing a single JAR or ZIP here does not create a new profile or install a pack's dependency list.

Launcher / mods

Update installed mods

Coffee Client checks known mods against the profile's exact Minecraft version and loader.

  1. Close Minecraft, select the profile, and open Mods.
  2. Go to Installed and click Check updates.
  3. When an update is found, select a mod and click its Update button, or use Update all for the available set.
  4. Read any failures in the window. A mod without a known project match is not updated just because its filename looks familiar.

Mods you imported manually may need Find artwork before Coffee Client can recognize them. CurseForge update checks need authorized CurseForge access. The launcher does not replace a stable release with a beta or alpha automatically.

Your look

Skins

Keep a local skin library and apply a favorite to your signed-in Java account.

  1. Click Skins in Coffee Client.
  2. Click Add skins, or drop PNG files onto Drop skin files.
  3. Select a skin from the library. Choose the Classic or Slim model; rename it and click Save changes if needed.
  4. Sign in with Microsoft, then click Apply skin to use it on that Java account.

Skin files must be PNG images sized 64 × 64 or 64 × 32, up to 1 MiB each. The library holds up to 50 skins. Duplicate PNG files are skipped.

You can download a saved skin PNG or delete a skin from its details. Bedrock skins are managed inside Minecraft for Windows, not through this Java skin library.

Your look

Capes

Capes come from your signed-in Minecraft account. Coffee Client can show and equip the ones that account owns.

  1. Sign in through Settings → Account, then open Skins and switch to Capes.
  2. Click Refresh to load the active account's capes. Select one to preview it.
  3. Use Equip cape to make it active, or Disable cape to use none.
  4. Give a cape a local nickname and save it if you want an easier label in your library.

The launcher cannot grant new capes. If the list is empty, check that the right Microsoft account is active and that it owns a cape.

Launcher / profiles

Duplicate a profile

Make a separate copy when you want to experiment or try another Minecraft version.

  1. Select the profile you want to copy in Launcher.
  2. Use the profile's duplicate control to open Duplicate profile.
  3. Give the copy a Profile name and choose its Minecraft version.
  4. Review any warning about mods that cannot change versions. Those mods will be copied disabled if you continue.
  5. Confirm the duplicate, then select and launch the new profile separately.

Some mods do not have a version that matches your target. Do not enable an incompatible mod in the new profile just because it worked in the original.

Servers / first server

Start a simple server

Host a Minecraft world on this computer while Coffee Client stays open.

  1. Open the Servers view and find New server.
  2. Enter a Server name. Choose Vanilla as Server type for an unmodded server, then choose a Minecraft version.
  3. Leave Memory (MB) at its default unless you know your computer needs something else.
  4. Enter Allowed players, one Minecraft username per line. Include your own username.
  5. Read and accept the Minecraft EULA, then click Create server.
  6. Select the new server and click Start. Wait for its status and log to show it is ready before connecting.

Create only saves the server. Start downloads and prepares what it needs, then runs it. The first start can take longer. The On this PC address is for this computer only.

Invite a friend

While creating or editing a server, turn on Share with friends using Server-Hosting and accept its separate consent. After the server starts, use the share address shown in the server details. Sharing uses a third-party relay and is intended for temporary sessions; do not assume the address is permanent. Only the usernames in Allowed players can join.

Keep Coffee Client open while people play. Closing Coffee stops its running servers. Use Stop and wait for the world to save before shutting down your computer. Remove removes the library entry, but server world files are kept on disk.

Beyond Vanilla

The server type list also includes Fabric, Quilt, Forge, NeoForge, Paper, Purpur, Folia, Spigot, SpongeVanilla, and Pumpkin where compatible versions are available. Pick the type your players and server content require. Some types need extra setup or are experimental; Vanilla is the easiest first server. See Choose a server type for the differences.

Servers / choosing

Choose a server type

The best choice depends on the content your group needs. Choose the type before making the server.

  • Vanilla: standard Minecraft with no server mod or plugin workflow. Start here for a simple world.
  • Fabric, Quilt, Forge, NeoForge: use server mods built for that loader and Minecraft version. Players may also need matching client mods.
  • Paper, Purpur, Spigot: use plugins rather than Fabric or Forge mods. Spigot needs Git and a compatible JDK for its first build.
  • Folia: a Paper-family server that requires plugins made for Folia. Its available BETA builds need explicit experimental consent.
  • SpongeVanilla: choose it for Sponge-compatible server content.
  • Pumpkin: an experimental native server using WASM plugins rather than Java JARs. It requires separate consent and does not offer Server-Hosting sharing.

Not every Minecraft release is available for every server type. The version list is filtered by the selected type. A client mod and a server plugin are not interchangeable.

Servers / content

Server mods & plugins

Server content lives with that server, not with your player profile.

  1. Stop the server and select it in Servers.
  2. Open its Mods, Plugins, or WASM plugins tab, depending on server type.
  3. Use Browse mods or Browse plugins to search compatible provider content where available, or click Import for a trusted local file.
  4. Use the switch next to an installed file to enable or disable it. Restart the server after content changes.

Manual imports are not compatibility-checked. Fabric, Quilt, Forge, and NeoForge use their matching server mods; Paper-family servers use plugins. Folia plugins need Folia support. Pumpkin uses WASM plugins and does not have the catalog search shown for other types. Vanilla has no content tab.

You cannot change server content while that server is preparing or running. If a newly added file prevents startup, stop the server, disable that file, and check the Server log.

Servers / day to day

Manage a server

Select a server to see its status, addresses, controls, settings, and log.

Change its settings

Stop the server before editing its Minecraft version, Memory (MB), optional Java executable, sharing choice, or Allowed players. Click Save profile when finished. Version upgrades back up the world and configuration in that server's backups folder; downgrades and changing server type need a separate server profile.

Use its controls

Start prepares and runs it. Stop asks Minecraft to save before closing. While running, Server command and Send pass a command to that server, and Server log shows its latest output. Use Open folder to inspect the world and backups. Change access through Allowed players; commands that disable the whitelist or change operators are blocked.

Remove takes the server out of your library, but keeps its world files on disk. It is not a backup or delete-world command. There is no in-app backup restore yet, so keep a separate copy of worlds you cannot afford to lose.

Servers / play together

Share a server

A server can be playable on your computer without being reachable by friends. Turn on sharing only when it is offered for your server and you need it.

  1. For a supported server type, turn on Share with friends using Server-Hosting and accept its separate consent.
  2. Keep the server's Allowed players list current. Include your own Minecraft username and each friend who should join, then save.
  3. Start the server and wait until it is running. Copy its Public address for friends; On this PC is only for your own computer.
  4. Keep Coffee Client and the server running while friends play. Stop the server when the session is over.

Sharing uses a third-party relay and can fail independently of the local server. Public addresses are temporary and may change. If the public address disappears, check the server status and log before sending an old address again. Do not disable the allowed-player list or online authentication to work around a connection error.

Troubleshooting / logs

Read logs

A useful error message is usually close to the time the problem happened.

Launcher and game

Open Console near the top of Coffee Client. Use its All, Warnings, Errors, and Fatal filters to narrow the view. Try the action again, then read the newest entries rather than an older message from a different profile.

Hosted server

In Servers, select the server and read Server log beneath its controls. A server that is still preparing has not necessarily failed. If it exits, note the last error and the server type and Minecraft version.

When reporting a problem, include what you clicked, the profile or server type, Minecraft version, and the relevant error text. Remove account tokens, sign-in codes, personal paths, and private addresses before sharing logs publicly.

Settings / updates

Update Coffee Client

Coffee Client checks for a new launcher release when it opens.

  1. When an Update available pop-up appears, click Update to download it, or Later to stay on this version for now.
  2. You can also open Settings → Updates and click Check for updates. Use Release notes to review what changed.
  3. When the download is ready, choose Restart to update and let Coffee Client finish installing.

Automatic launcher updates work for the installed Windows version and writable Linux x64 AppImages. Development builds, Windows portable builds, and unpacked Linux builds do not auto-update. This is separate from changing a Minecraft profile's game version.

Do not close the launcher in the middle of an update unless it reports an error. If an update fails, check the message in Settings → Updates and try again when your connection is stable.

Settings / personal choices

Appearance & Discord

Change how the launcher looks without changing the Minecraft profile you play.

Launcher appearance

Open Settings → Appearance. Coffee type switches the launcher's light and dark colors. Background beans controls the animated background. This website stays in dark mode; the guide built into Coffee Client follows the launcher theme. The standalone website has a separate Theme selector for system, light, or dark mode.

Discord activity

Open Settings → Discord and choose whether to Show launcher activity on Discord. Discord must be open on your computer for that status to appear. The Discord server buttons open community links; they are not required to use the launcher.

Settings / more control

Advanced features

Turn on extra controls only when you need to change more than the normal profile settings.

  1. Open Settings.
  2. Turn on the Advanced switch in the Settings menu.
  3. For Java profiles, Files and Performance become available. The Minecraft version list can also show more versions supported by the chosen loader.
  4. Turn Advanced off again to return to the simpler view. Check the selected Minecraft version before launching, since a hidden snapshot choice may be replaced in the list.

Looking for pre-release game versions? See Show Minecraft snapshots.

Game files and Java

With a Java profile selected, open Settings → Files to see its Game folder, Java command or path, and Release channel choices. Use Browse for a folder, then Save changes. If versions look out of date, use the Reload Minecraft versions control; the loader still decides which versions can be selected.

Memory

Open Settings → Performance to set Minimum memory (MB) and Maximum memory (MB). The Half RAM shortcut sets a starting maximum from your computer's memory. Click Save changes. These are game-profile settings; a hosted server has its own Memory (MB) field.

Advanced controls are for Java profiles, not Bedrock. Extra version choices are still limited by loader support. Changing Java, memory, or game files without knowing what a modpack needs may stop it launching.

Settings / game versions

Show Minecraft snapshots

Advanced mode adds available snapshot and pre-release choices to the Java version lists.

  1. On the Launcher screen, open Settings and turn on Advanced in the Settings menu.
  2. For an existing Java profile, open its Minecraft version list on the Launcher screen. For a new profile, click New profile / Import pack, choose New profile and a Mod loader, then open Minecraft version.
  3. Choose a snapshot or pre-release from the versions available for that loader.

There is no separate snapshot switch. Release channel under Settings → Files does not control which Minecraft versions appear. A mod loader may not support the snapshot you want, so its list can be shorter than Vanilla's.

If you turn Advanced off later, snapshot-type choices are hidden again. Check the version shown for your profile before launching.

Files / keeping your work

Find your files

Use the launcher to open the folder for the thing you are working on. Avoid guessing from another profile's path.

Player profiles

Select the profile, open Mods, Shaders, or Texture Packs, then click Open folder to reach that content folder. With Advanced on, Settings → Files shows the profile's Game folder. Worlds, screenshots, and configuration belong to that profile's game files.

Hosted servers

Select a server in Servers and click Open folder. Its world and content remain there after you remove the server from the list. Version upgrades keep a backups folder there, but Coffee Client does not have an in-app restore button.

Before deleting files manually, stop the game or server and copy worlds and settings you want to keep. The profile and server Remove actions only remove library entries; they do not erase folders for you.

Your choices

Privacy & sharing

Not every feature sends the same information to the same place. These are the choices worth knowing about.

  • This guide is bundled with the launcher for offline use. The web version is served by its website host; the optional local server runs only on your computer.
  • Microsoft sign-in connects the Java account you choose for authenticated play and account cosmetics. Modpack import does not copy account credentials.
  • Find artwork sends fingerprints of installed files in the selected profile to Modrinth to look for exact matches. The files themselves stay on your computer.
  • Browse and downloads contact the selected content provider. CurseForge downloads need authorized access configured for this launcher.
  • Server-Hosting is off until you enable it for a supported server and accept its separate consent. It uses a third-party relay for a temporary public address.

Keep sign-in codes and account details out of screenshots and logs you share. If you only want to play locally, you do not need to enable server sharing.

Quick checks

When something goes wrong

Most problems are easier to narrow down one change at a time.

A profile will not launch

Check that its Minecraft version matches its loader and mods. If you just added a mod, disable it and try again. Imported packs may need their first download to finish before they can launch.

A modpack import stops

Confirm it is a Modrinth .mrpack or an exported CurseForge .zip, not a ZIP of loose mods. CurseForge exports normally list files to download; missing authorized access or a publisher-restricted file can stop the import. The failed import does not add a half-finished profile. See Import a modpack.

A mod or pack is missing

Check that you selected the intended profile before opening Mods, Shaders, or Texture Packs. Look under Installed; a disabled mod stays listed but will not load. A resource pack still needs to be enabled in Minecraft.

Online play or skins do not work

Go to Settings → Account and make sure the correct Microsoft account is active. Applying a Java skin requires a connected account. Bedrock skin changes happen inside Minecraft for Windows.

A server will not start

Select the server and read its Server log and status. The first start may still be preparing downloads or Java. Check the selected server version, available memory, and any extra requirements of its server type.

A friend cannot connect

Make sure the server says it is running, the friend is listed under Allowed players, and you are giving them the share address, not On this PC. Sharing needs its separate consent and a working relay connection.

An update does not install

Check Settings → Updates for its status and release notes. Automatic updates are not available for development or portable builds. A Minecraft game-version change is separate from a launcher update.

When asking for help, include the Coffee Client version, Minecraft version, loader or server type, what you clicked, and the relevant error or log text. Do not share Microsoft sign-in codes or private account details.
